How it works

Three steps to sovereignty

1

Run one command

One static binary with the database and UI built in. Runs on a $4 VPS, a Raspberry Pi, or your laptop.

curl -fsSL https://denly.xyz/install.sh | sh
2

Claim your keys

Keys generate on your device and never leave it. Link your Nostr or ATProto identity to prove the den is yours.

denly init
3

Open your den

Publish your page, start dropping files, arm your switch. Localhost, Tailscale, Tor, or your own domain.

denly serve
We host availability,
not secrets.

Every sensitive payload is encrypted on your device before it touches any server — yours or ours. Self-host the whole thing for free, forever. If a hosted version ever exists, it will hold ciphertext it cannot read, and you can export and leave anytime. That's not a promise; it's the architecture.

Roadmap

Built in public, shipped in phases

Follow along on GitHub and X. Every phase launches with demos, not promises.

NOW

Phase 0 — Foundations

Done and open source: the single binary, embedded storage, signed release pipeline, and one-command installer. No product features yet.

NEXT

v1 — Core den

Presence page, Nostr identity verification, encrypted drops with receive box, and the CLI.

THEN

v2 — Deadhand

The dead man's switch: heartbeats, escalation, encrypted payload release, Arweave permanence, drill mode.

MAYBE

Hosted tier

Only if the waitlist demands it. Same code, same crypto, isolated per-customer instances. Export-and-leave anytime, guaranteed by design.
